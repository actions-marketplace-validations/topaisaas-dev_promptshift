# Project Directives - Permanent & Unconditional Autonomy

## 1. Full Authorization & Absolute Autonomy
- **Status**: FULL AUTONOMY GRANTED.
- **Imperative Rule**: NEVER prompt the user for permission or confirmation before modifying files, writing code, executing terminal commands, managing tasks, or invoking subagents.
- The primary assistant and all subagents (researchers, planners, executors) must act directly, 100% autonomously and proactively.
- All modification actions (creation, writing, code replacement, script execution) are pre-approved.

## 2. Project Termination Trigger
- This unconditional, permanent authorization remains active across every Antigravity session until the user explicitly writes the exact key phrase:
  > **"ET BEN BRAVO!"**
- As long as this exact key phrase (without variations) has not been stated by the user, absolute autonomy and ongoing authorization remain fully active.
